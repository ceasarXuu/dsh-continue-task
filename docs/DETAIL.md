# 任务续传

在应用重启、网络中断或模型额度不足后，把未完成的任务继续下去。

## 它做什么

DSH 的会话日志会记录每个回合为什么结束。本插件读取这些事实，并按策略追加一条普通会话消息或切换到备用模型：

- **应用意外退出 / 强制退出**：启动后自动继续上一轮未完成的任务。
- **应用正常退出但停在步骤边界**：不自动继续，视为用户主动结束。
- **应用正常退出时仍有执行中的步骤**：下次启动后继续。
- **网络、超时、服务端或限流错误**：按指数退避重试；网络恢复后自动继续。
- **额度耗尽、凭据失效或模型不可用**：切换到配置的备用 provider/model，再继续。
- **用户主动停止、子会话、已归档会话**：不会自动恢复。

所有恢复都会出现在对话中，可随时停止；手动操作会取消该会话的自动恢复。

## 如何配置

打开 **Settings → 任务续传**：

- 总开关与通用恢复提示语。
- 启动后继续：等待时间、回看窗口、每次最多恢复数、重启续传消息。
- 网络重试：重试次数、退避上限、总等待时间。
- 额度切换：最多切换次数、最多 3 个备用模型。
- 运行状态：待恢复项、最近动作、手动扫描与取消。

默认只回看最近 30 分钟、每次最多恢复 2 个会话，避免首次安装时唤醒大量旧任务。

## 限制

- 网络恢复使用退避重试，不主动探测网络状态。
- 切换模型只影响当前会话，不修改全局默认模型。
- 崩溃前尚未落盘的用户输入无法恢复。
